To search Google you need two free codes of your own. Google does not let a website search images without them. It takes about three minutes, it costs nothing, and both codes stay in this browser only.

  1. Open Programmable Search Engine. Name it anything, turn Search the entire web ON, and create it. Then open its Overview and copy the Search engine ID.
  2. In that same page turn Image search ON.
  3. Open this Google page and press Get a Key. Copy the API key.
  4. Paste both below.
