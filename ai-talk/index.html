POWERED BY YOUR OWN OPENAI KEY

Paste an OpenAI API key and this becomes a full chat client: streaming replies, every model on your account, image generation, voice in and voice out, and image understanding.

Get a key at platform.openai.com/api-keys. For everything here to work, give it write access to Model capabilities (that single permission covers chat, images, speech and transcription).

Read this first. This site is static files on GitHub Pages — there is no server to hide a key behind. Your key is kept in this browser's local storage and sent straight to OpenAI, never to anyone else. But anyone who can use this device can read it, so use a dedicated key with a spending limit, and delete it from your OpenAI dashboard if it ever leaks. Never hard-code a key into the page itself — it would be public to the whole internet.
