🤖 Soccer AI key
Soccer AI uses OpenAI. Paste your own API key — it's saved only on this device (never uploaded), and powers the 🤖 Soccer AI screen.
1. Go to platform.openai.com/api-keys and sign in.
2. Tap “Create new secret key”, name it, and copy it (starts with sk-).
3. Add a little credit under Billing, and set a low monthly usage limit.
4. Paste it above and Save. ⚠️ A browser-side key is visible to anyone using this device or watching network traffic — keep the limit low and rotate it if it leaks.
